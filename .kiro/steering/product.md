# Product Overview

YouTube Channel Manager - A web application for managing and organizing YouTube channels with ebook generation capabilities.

## Core Features

- User authentication with email-based login
- Add and manage YouTube channels via URL
- Automatic video fetching from YouTube channels
- Video metadata storage (title, description, duration)
- Ebook generation from channel videos
- Channel and video deletion with cascade cleanup

## User Flow

1. Users sign in with email authentication
2. Add YouTube channels by pasting channel URLs
3. System automatically fetches and stores video metadata
4. Users can view channel details and associated videos
5. Generate ebooks from selected videos
6. Delete channels (removes all associated videos and ebooks)
