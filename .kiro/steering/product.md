# Product Overview

A YouTube channel management application that allows users to:
- Add and manage YouTube channels by URL
- Automatically fetch and display videos from channels
- View channel details and video listings
- Generate ebooks from video collections (planned feature)

The app uses AWS Amplify for backend services with user authentication, real-time data sync, and serverless functions for YouTube API integration.

## Key Features
- User authentication with email login
- Real-time channel and video updates
- Automatic video fetching when channels are added
- Channel and video deletion with cascade cleanup
- Navigation between channel list and detail views
