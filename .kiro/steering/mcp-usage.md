# MCP Server Usage Guidelines

## Proactive MCP Server Evaluation

For EVERY user prompt, you MUST evaluate whether any available MCP servers can help:

1. **Don't wait for explicit requests** - proactively use MCP tools when they're relevant

2. **When in doubt**, prefer using an MCP tool over relying solely on training data.

## Available MCP Servers

Check available MCP tools at the start of complex tasks and consider which ones apply to the user's request.
